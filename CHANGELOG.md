# Changelog

All notable changes to RepoChat will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows semantic versioning while it prepares for marketplace publishing.

## [0.0.1] - 2026-09-08

### Added

- Initial VS Code extension scaffold in TypeScript.
- RepoChat Activity Bar container and sidebar webview.
- Polished local chat preview UI.
- Local in-memory message composer with webview-to-extension message passing.
- `Share in RepoChat` editor context command for selected code.
- Code attachments with repository, file path, line range, selected text, branch, and commit metadata.
- Attachment open action that reveals the referenced file and lines in VS Code.
- Local `.vsix` packaging script.
- Marketplace-ready PNG icon asset.
- Public-readiness documentation for installation, contribution, support, and security.
- Git repository detection for workspace root, remote URL, normalized repository slug, branch, and commit SHA.
- Strict TypeScript, ESLint, Prettier, and Node test setup.
- Project documentation and release checklist for GitHub and Marketplace readiness.
